# Projeto Aviação ANAC

Projeto de análise de dados relacionados à aviação brasileira, utilizando informações disponibilizadas pela Agência Nacional de Aviação Civil (ANAC).

## Sobre o projeto

Este projeto tem como objetivo trabalhar com dados do setor de aviação para realizar uma análise das informações disponíveis, permitindo organizar, tratar e visualizar os dados de forma mais clara.

A partir dos dados utilizados no projeto, são realizadas etapas de preparação, exploração e análise, buscando identificar informações relevantes sobre o cenário da aviação brasileira.

## Objetivos

- Trabalhar com dados públicos relacionados à aviação;
- Realizar o tratamento e a organização dos dados;
- Explorar as informações disponíveis;
- Identificar padrões e informações relevantes;
- Criar visualizações para facilitar a interpretação dos dados;
- Apresentar os resultados de forma clara e objetiva.

## Dados

Os dados utilizados no projeto são relacionados ao setor de aviação brasileira e têm como fonte a **Agência Nacional de Aviação Civil (ANAC)**.

Os arquivos de dados são utilizados como base para as etapas de tratamento, análise e visualização realizadas no projeto.

## Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Etapas do projeto

O projeto é organizado nas seguintes etapas:

1. **Importação dos dados**
   - Carregamento dos arquivos utilizados na análise.

2. **Tratamento dos dados**
   - Organização das informações;
   - Verificação dos dados;
   - Tratamento de valores quando necessário.
   - Utilização da Arquitetura Medalhão.

3. **Análise exploratória**
   - Exploração das principais características dos dados;
   - Identificação de informações relevantes.

4. **Visualização**
   - Criação de gráficos;
   - Apresentação visual dos resultados encontrados.

5. **Interpretação**
   - Análise das informações obtidas a partir dos dados.
